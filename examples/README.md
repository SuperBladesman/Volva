# Example data (synthetic)

These patterns are **synthetic**, generated by `tests/synth.py`. Each is a true Voigt convolution with a Cu Kα₁/Kα₂ doublet and Poisson noise. Use them to learn the application and check an installation, never as reference data.

| File | Content | Expected result |
|---|---|---|
| `SYNTHETIC_LaB6_standard.xy` | LaB₆ standard, instrument profile only | Calibrates with 20 peaks; position check passes |
| `SYNTHETIC_LaB6_profile.json` | profile made from the file above | Load it with **Load…** |
| `SYNTHETIC_CeO2_Lvol34nm.xy` | CeO₂, size only | L_vol ≈ 33.9 nm, no strain |
| `SYNTHETIC_CeO2_Lvol34nm_strain0.106pc.xy` | CeO₂, size + Gaussian strain | L_vol ≈ 33.9 nm, e ≈ 0.106 %. Scherrer is flagged as a lower bound |
